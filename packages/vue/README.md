# @xunserver-jsf/vue

Vue Renderer：`FormRenderer` / `ViewRenderer` / `FieldRenderer`、只读 composables，以及 `defineVueUIAdapter()`。

```bash
pnpm add @xunserver-jsf/core @xunserver-jsf/vue
pnpm add vue
```

`vue` 是 peer dependency。UI 组件库通过独立 adapter 包注入，例如 `@xunserver-jsf/element-plus`。

文档：https://xunserver.github.io/json-schema-form/guide/getting-started.html  
API：https://xunserver.github.io/json-schema-form/api/
