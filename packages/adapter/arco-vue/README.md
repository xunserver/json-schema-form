# @xunserver-jsf/arco-vue

Arco Design Vue UI Adapter，位于 Vue Renderer 之上。

```bash
pnpm add @xunserver-jsf/core @xunserver-jsf/vue @xunserver-jsf/arco-vue
pnpm add vue @arco-design/web-vue
```

导出 `arcoVueAdapter`、`createArcoVueAdapter()`、`extendArcoVueAdapter()`。`vue` 与 `@arco-design/web-vue` 是 peer dependency。

文档：https://xunserver.github.io/json-schema-form/
