# @xunserver-jsf/element-plus

Element Plus UI Adapter，位于 Vue Renderer 之上。

```bash
pnpm add @xunserver-jsf/core @xunserver-jsf/vue @xunserver-jsf/element-plus
pnpm add vue element-plus
```

导出 `elementPlusAdapter`、`createElementPlusAdapter()`、`extendElementPlusAdapter()`。`vue` 与 `element-plus` 是 peer dependency。

文档：https://xunserver.github.io/json-schema-form/
