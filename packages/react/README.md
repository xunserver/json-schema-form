# @xunserver-jsf/react

React Renderer：`FormRenderer` / `ViewRenderer` / `FieldRenderer`、只读 hooks，以及 `defineReactUIAdapter()`。

```bash
pnpm add @xunserver-jsf/core @xunserver-jsf/react
pnpm add react
```

`react` 是 peer dependency。UI 组件库通过独立 adapter 包注入，例如 `@xunserver-jsf/antd`。

文档：https://xunserver.github.io/json-schema-form/
